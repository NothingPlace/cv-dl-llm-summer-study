# AI 核心概念速查笔记：从视觉模型到大语言模型 (LLM)

## 1. 计算机视觉四大任务：分类 / 检测 / 分割 / ViT

这四种任务是计算机视觉（CV）领域最基础的应用，难度和输出粒度逐步递进。

| 任务类型 | 核心目标 | 输出粒度 | 典型应用 |
| :--- | :--- | :--- | :--- |
| **分类 (Classification)** | 判断这张图里**是什么**（单一主体）。 | 图片级别（一个标签） | 识别图片是猫还是狗。 |
| **检测 (Detection)** | 判断图里**有什么，分别在哪里**。 | 实例级别（边界框 BBox） | 自动驾驶中识别车辆和行人位置。 |
| **分割 (Segmentation)** | 区分**前景和背景**，精确到像素级别。 | 像素级别（掩码 Mask） | 医学影像中的病灶区域提取。 |
| **ViT (Vision Transformer)** | **不是任务**，而是一种**架构**。将图片切成 Patch（类似 Token），用 Transformer 处理，替代传统 CNN。 | 可作为上述三种任务的骨干网络 | 用于分类（ViT）、检测（DETR）等。 |

## 2. 大语言模型 (LLM) 核心概念解析

理解 LLM 运作方式的关键术语：

- **Token (词元)**：LLM 处理文本的最小单元。**不是单词**，而是子词（如 "Chat" -> "Chat", "GPT" -> "G"+"PT"）。LLM 计费按 Token 数量算。
- **Embedding (嵌入/向量)**：将 Token 转换成计算机能理解的**高维数字向量**。语义越近的词，向量在空间中的距离越近（如 “国王” 和 “皇帝”）。
- **Transformer (变换器)**：目前所有主流 LLM 的底层架构。核心是 **Self-Attention（自注意力机制）**，它能让模型在处理某个词时，**关注输入序列中所有其他词**，从而理解上下文。
- **Attention (注意力)**：计算词与词之间的相关性权重。例如在 “苹果很好吃” 中，“好吃” 会把大部分注意力放在 “苹果” 上。
- **Context Window (上下文窗口)**：模型一次性能“记住”或“看到”的 Token 最大数量。窗口越大，模型能处理的文本越长（如 Claude 支持 200K Token）。
- **Prompt (提示词)**：用户输入给 LLM 的指令或问题。
- **生成参数 (Temperature / Top-p)**：控制模型“创造力”的开关。
  - **Temperature (温度)**：值越高（>1），输出越随机、越有创意；值越低（→0），输出越保守、越确定。
  - **Top-p (核采样)**：只从概率累积和达到 p% 的词语中抽样，过滤掉极不可能的选项。

## 3. 大模型 vs 普通深度学习模型（本质区别）

| 维度 | 普通深度学习模型（如 ResNet） | 大模型 (LLM / 基础模型) |
| :--- | :--- | :--- |
| **核心范式** | **discriminative**（判别式）：学习边界，区分类别。 | **generative**（生成式）：学习概率分布，预测下一个词/像素。 |
| **泛化能力** | **窄**：专做一件事（如只识别猫）。 | **广**：具备 In-context Learning（上下文学习），可通过提示词完成多种任务。 |
| **规模** | 百万级参数。 | 十亿/万亿级参数。 |
| **数据依赖** | 需大量**标注**数据。 | 需海量**无标注**文本/图像进行预训练。 |
| **涌现能力** | 无。 | 随着参数增大，突然出现小模型没有的能力（如逻辑推理、代码生成）。 |

## 4. 任务差异对比

以下例子对比“普通分类模型”（如 BERT-base 或 ResNet）与“生成式大模型”（如 GPT-4）。

| 场景 | 普通分类模型（判别式） | 生成式大模型（生成式） | 核心差异点 |
| :--- | :--- | :--- | :--- |
| **1. 情感分析** | 输入影评，输出 `[正面, 负面]` 概率（如 0.9）。 | 输入影评，输出 `“这部电影的剧情很紧凑，但结局略显仓促。”`（完整的分析评语）。 | 分类模型只给**标签**；LLM 给**解释**。 |
| **2. 文本翻译** | 无法直接做翻译（除非专门训练一个 Seq2Seq 模型）。 | 输入 `“Translate to Chinese: Hello”`，输出 `“你好”`。 | 分类模型无法通过**指令**改变任务；LLM 可以零样本（Zero-shot）完成。 |
| **3. 数学题求解** | 无法处理（分类器只能做线性/非线性分类）。 | 输入 `“鸡兔同笼，头共 10 个，脚共 28 只，问鸡兔各几只？”`，输出详细的**解题步骤**。 | 分类模型无**推理链**（Chain-of-Thought）能力。 |
| **4. 信息抽取** | 输入句子，输出预定义的实体类型（如 PER, LOC）。 | 输入 `“帮我提取人名和地点：张三去了北京。”`，输出 `{"人名":"张三", "地点":"北京"}`（按指定 JSON 格式）。 | LLM 能理解复杂的**格式指令**。 |
| **5. 代码生成** | 完全不可行。 | 输入 `“写一个 Python 函数读取 CSV 文件”`，输出可运行的代码块。 | 分类模型不具备**程序合成**能力。 |

## 5. LLM 能做什么 vs 不能做什么（边界认知）

### ✅ LLM 能做什么（擅长领域）

- **文本创作**：写邮件、诗歌、营销文案。
- **代码辅助**：Debug、解释代码、跨语言转换（如 Java -> Python）。
- **知识问答**：基于训练数据中的事实性知识回答（注意：存在幻觉）。
- **角色扮演**：模拟特定人格或语气回复。
- **非结构化数据整理**：将杂乱的文本提取为结构化表格。

### ❌ LLM 不能做什么（固有限制与风险）

- **数学计算与逻辑严谨性**：本质是“文字接龙”，不会真正的算术（8.11 比 8.8 大？LLM 容易答错）。**解决**：必须开启代码解释器（Code Interpreter）或调用外部计算工具。
- **事实准确性（幻觉 Hallucination）**：会“一本正经地胡说八道”，捏造不存在的事实时（幻觉问题）。**本质**：模型只懂概率，不懂真假。
- **实时数据与隐私**：训练数据截止至某一时间点（如 2023 年），不知道今天天气。且**无法保证隐私**，输入的数据会被用于训练（需注意脱敏）。
- **物理世界交互**：没有身体，无法直接控制机器人拿起杯子（需结合具身智能）。
- **因果推理**：只能看到相关性，很难真正理解复杂的因果关系（如经济学调控后果）。

## 6. 特别关注：幻觉 (Hallucination) 与 Attention

- **为什么有幻觉？** 因为 LLM 的训练目标是**最大化下一个 Token 的概率**，而不是**求证事实的真伪**。当它不知道答案时，它倾向于“编造”一个最连贯的接续。
- **Attention 的作用**：正是 Attention 机制让 LLM 在生成当前词时，能回头“看” Prompt 里的关键信息，这在一定程度上能缓解幻觉（防止跑题），但无法根除。

### 二、各项目详细分析

### 项目 1：基于 CNN 的服装图像分类

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | Fashion-MNIST：10 类服装（T恤、裤子、裙子、外套、凉鞋等），28×28 灰度图，训练集 6 万张，测试集 1 万张。 |
| **技术路线** | ① 搭建 MLP 作为 Baseline；② 搭建简易 CNN（2-3 层 Conv + Pooling）；③ 对比两者效果，分析 CNN 优势（参数共享、局部感受野）；④ 可视化卷积核和特征图。 |
| **可扩展方向** | 加入 BatchNorm、Dropout、数据增强，尝试 ResNet-18 微调 |

### 项目 2：基于深度学习的猫狗图像分类

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | Dogs vs Cats（Kaggle 经典）：25,000 张彩色图片（猫狗各一半），尺寸不一。建议只用 2,000-5,000 张以加快训练。 |
| **技术路线** | ① 使用 ImageFolder 加载数据，做 Train/Val/Test 划分；② 应用数据增强（随机旋转、翻转、裁剪、归一化）；③ 加载预训练 ResNet-18（或 AlexNet），冻结主干网络，替换全连接层为二分类头；④ 微调（Fine-tune）最后几层；⑤ 输出预测结果并可视化。 |

### 项目 3：基于 ResNet 的花卉分类

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | Oxford Flowers 102：102 类英国花卉，每类 40-258 张图片，共约 8,000 张，尺寸较大且色彩丰富。也可用 Flowers Recognition 小数据集（5 类，4,000 张）。 |
| **技术路线** | ① 加载预训练 ResNet-34/50（ImageNet 权重）；② 替换最后一层全连接为 102/5 类输出；③ 分阶段调参：先冻结主干训练分类头，再解冻部分层做 Fine-tune；④ 使用学习率衰减（StepLR / CosineAnnealing）；⑤ 输出 Top-1/Top-5 准确率，绘制混淆矩阵。 |

### 项目 4：简单表面缺陷/零件分类

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | ① NEU-CLS（东北大学表面缺陷数据集）：6 类钢材缺陷（裂纹、划痕、夹杂等），1,800 张灰度图；② 或使用 Kaggle 的 Surface Crack Detection（二分类）；③ 也可自制小型零件数据集（螺丝/垫片等）。 |
| **技术路线** | ① **传统图像处理 Baseline**：用 OpenCV 提取纹理特征（LBP / HOG / GLCM），送入 SVM 或随机森林分类；② **CNN 路线**：搭建简易 CNN 或使用 ResNet-18 微调；③ 对比传统方法与深度学习的效果差异；④ 分析误判样本，讨论工业场景中的光照、角度影响。 |

### 项目 5：U-Net 语义分割入门

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | ① ISBI 2012 细胞分割（U-Net 原始论文数据集，30 张训练图）；② Oxford Pets（宠物分割，可做二分类前景/背景）；③ CamVid（道路场景分割，11 类，可用于自动驾驶入门）。 |
| **技术路线** | ① 从零实现 U-Net 架构（编码器-解码器 + 跳跃连接）；② 使用 Dice Loss + BCE Loss 组合损失函数；③ 预测像素级掩码，计算 mIoU 和 Dice Coefficient；④ 可视化输入图像 → 预测掩码 → 真实掩码对比。 |

### 项目 6：YOLO 目标检测入门复现

| 维度 | 详细说明 |
| :--- | :--- |
| **数据集** | ① PASCAL VOC 2012（20 类，约 11,000 张）；② COCO 子集（80 类，数据量大）；③ 或自制小数据集（如"检测桌面上的杯子/手机/键盘"）。 |
| **技术路线** | ① 使用 Ultralytics YOLOv8 官方库，加载预训练权重（yolov8n.pt）；② 在自己的数据集上微调（修改 dataset.yaml，配置类别数）；③ 调整超参数（imgsz, batch, epochs, patience）；④ 输出检测结果（边界框 + 类别 + 置信度）；⑤ 计算 mAP@0.5 和 mAP@0.5:0.95。 |

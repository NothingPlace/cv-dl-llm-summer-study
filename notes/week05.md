# 卷积神经网络（CNN）核心概念笔记

## 1. 卷积 (Convolution)

- **本质**：一种数学运算，在CNN中用于提取输入数据的特征。
- **操作**：卷积核（滤波器）在输入数据（如图像）上滑动，对应元素相乘后求和，得到输出特征图上的一个值。
- **直观理解**：可以看作是一种“特征匹配”过程，卷积核关注的是局部区域内的特定模式（如边缘、纹理等）。
- **数学表达式**（二维离散卷积）：
  \[
  $S(i,j) = (I * K)(i,j) = \sum_m \sum_n I(i+m, j+n) K(m, n)$
  \]

## 2. 卷积核 (Kernel / Filter)

- **定义**：一个小的权重矩阵，是CNN中可学习的参数。
- **作用**：用于检测输入中的某种特定特征。不同的卷积核可以提取不同的特征。
- **常见尺寸**：3x3, 5x5, 7x7 等。通常尺寸越小，参数量越少，网络越深。
- **深度**：卷积核的深度必须与输入数据的通道数相同。

## 3. 填充 (Padding)

- **定义**：在输入数据的边界周围添加额外的像素层（通常填充0）。
- **目的**：
  1. **保持空间尺寸**：防止经过多次卷积后特征图尺寸过快缩小。
  2. **利用边缘信息**：让卷积核也能处理输入图像的边缘像素，边缘信息被使用的次数与中心像素相同。
- **类型**：
  - **Valid / 不填充**：输出尺寸 = 输入尺寸 - 卷积核尺寸 + 1。
  - **Same / 半填充**：在输入四周填充，使得输出尺寸等于输入尺寸（除以步长后向上取整）。

## 4. 步长 (Stride)

- **定义**：卷积核在输入数据上每次滑动的像素数。
- **作用**：控制输出特征图的空间尺寸。步长越大，输出尺寸越小，计算量也越小。
- **影响**：较大的步长可以起到降采样的作用，但可能会丢失一些细节信息。
- **输出尺寸计算公式**（假设输入高度 H，卷积核大小 K，填充 P，步长 S）：
  \[
  $\text{输出尺寸} = \left\lfloor \frac{H - K + 2P}{S} \right\rfloor + 1$
  \]

## 5. 池化 (Pooling)

- **定义**：一种下采样操作，对特征图的局部区域进行聚合统计。
- **作用**：
  1. **降低特征图分辨率**，减少参数量和计算量。
  2. **增强特征的不变性**（平移、旋转等）。
  3. **防止过拟合**。
- **常见类型**：
  - **最大池化 (Max Pooling)**：选取局部区域中的最大值。更关注最显著的特征。
  - **平均池化 (Average Pooling)**：计算局部区域的平均值。更关注整体的背景信息。

## 6. 通道 (Channel)

- **定义**：特征图的“深度”维度。
- **输入通道**：例如，彩色RGB图像有3个通道，灰度图像有1个通道。
- **输出通道**：由卷积核的数量决定。每个卷积核生成一个独立的特征图，所有特征图堆叠在一起形成输出特征图的通道。
- **全连接映射**：卷积操作实际上是在输入的所有通道上进行，并将结果相加，生成输出的一个通道。

## 7. 特征图 (Feature Map)

- **定义**：经过卷积或池化操作后得到的输出结果。
- **含义**：特征图上的每个像素代表原图中某个局部区域响应某一特定卷积核的强度，值越大表示该区域越符合卷积核所代表的特征。
- **层级特征**：
  - **浅层特征图**：提取边缘、颜色、纹理等低级特征。
  - **深层特征图**：提取组合、物体部件等高级语义特征。

## 8. LeNet-5（经典CNN架构）

- **历史地位**：Yann LeCun 于1998年提出，用于手写数字识别（MNIST），是现代CNN的鼻祖。
- **网络结构**（简化版）：
  1. **输入层**：32x32 灰度图像。
  2. **卷积层 C1**：6个5x5卷积核，输出 6@28x28。
  3. **池化层 S2**：2x2平均池化，输出 6@14x14。
  4. **卷积层 C3**：16个5x5卷积核，输出 16@10x10。
  5. **池化层 S4**：2x2平均池化，输出 16@5x5。
  6. **全连接层 C5**：120个神经元。
  7. **全连接层 F6**：84个神经元。
  8. **输出层**：10个类别（使用RBF或Softmax）。
- **特点**：先进行卷积和池化提取特征，最后由全连接层进行分类。

## CNN 结构说明

### 1. 标准流程

输入 → [卷积+激活] → [池化] → [卷积+激活] → [池化] → ... → [全连接] → 输出

### 2. 各层作用

| 层 | 作用 | 关键参数 |
| ---- | ------ | ---------- |
| 卷积层 | 提取局部特征（边缘、纹理等） | 核数量、核尺寸、步长、填充 |
| 激活层 | 引入非线性，常用ReLU | 无参数 |
| 池化层 | 压缩尺寸，减少计算量 | 窗口大小、步长 |
| 全连接层 | 组合特征，做分类/回归 | 输入维度、输出维度 |
| 输出层 | 多分类用Softmax，二分类用Sigmoid | 类别数 |

### 3. 核心公式

**卷积输出尺寸**：
输出 = (输入 - 核大小 + 2×填充) ÷ 步长 + 1

**卷积参数量**：
参数量 = (核高×核宽×输入通道 + 1) × 输出通道

### 4. 常用设置

| 配置 | 推荐值 |
| ------ | -------- |
| 卷积核 | 3×3 |
| 卷积步长 | 1 |
| 池化 | 2×2 最大池化，步长2 |
| 填充 | same模式：padding = 核尺寸÷2 |
| 通道变化 | 逐层翻倍（32→64→128） |
| 激活函数 | 隐藏层用ReLU，输出层用Softmax |

### 5. LeNet-5 结构示例

```text
输入 32×32×1
    ↓
卷积 5×5，6个核 → 28×28×6
    ↓
平均池化 2×2 → 14×14×6
    ↓
卷积 5×5，16个核 → 10×10×16
    ↓
平均池化 2×2 → 5×5×16
    ↓
全连接 → 120 → 84 → 10（输出类别）

总参数量：约 6 万
```

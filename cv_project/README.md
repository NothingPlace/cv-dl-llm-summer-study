# 基于 ResNet-18 的 Flowers102 花卉分类项目方案与数据集说明

## 一、项目基本信息

| 信息项 | 内容 |
| :--- | :--- |
| **项目名称** | 基于 ResNet-18 迁移学习的 Flowers102 花卉分类 |
| **任务类型** | 图像分类（102 类） |
| **数据集** | Oxford 102 Flowers（torchvision 内置） |
| **核心模型** | ResNet-18 + ImageNet 预训练权重 |
| **技术路线** | 迁移学习 + 分阶段微调 |
| **技术栈** | PyTorch、torchvision、YAML、Matplotlib |
| **项目周期** | 第 10-12 周 |

## 二、数据集说明

### 2.1 数据集概况

| 信息项 | 内容 |
| :--- | :--- |
| **数据集名称** | Oxford 102 Flowers |
| **来源** | 牛津大学 VGG 组，torchvision 内置 |
| **类别数** | 102 类英国常见花卉 |
| **总样本数** | 8,189 张 |
| **图片通道** | RGB（3 通道） |
| **原始尺寸** | 不均匀，需统一 resize 到 224×224 |
| **类别分布** | 不平衡，每类 40-258 张 |

### 2.2 数据划分（官方）

| 划分 | 图片数量 | 占比 | 说明 |
| :--- | :--- | :--- | :--- |
| **训练集** | 1,020 | 12.5% | 每类固定 10 张 |
| **验证集** | 1,020 | 12.5% | 每类固定 10 张 |
| **测试集** | 6,149 | 75.0% | 剩余图片，每类至少 20 张 |
| **总计** | 8,189 | 100% | — |

### 2.3 数据集特点

1. **训练集极小**:仅 1,020 张，每类 10 张 
2. **类别不平衡**:每类 40-258 张 
3. **类间相似**:部分花卉外观接近 
4. **测试集占比大**:75% 用于测试 
5. **图片尺寸不一**:原始分辨率差异大 

### 2.4 数据预处理与增强

**基础预处理（训练/验证/测试通用）：**

| 步骤 | 参数 |
| :--- | :--- |
| Resize | 224×224 |
| 归一化均值 | [0.485, 0.456, 0.406]（ImageNet） |
| 归一化标准差 | [0.229, 0.224, 0.225]（ImageNet） |

**训练集数据增强：**

| 增强方法 | 参数 | 作用 |
| :--- | :--- | :--- |
| 随机水平翻转 | p=0.5 | 提升镜像不变性 |
| 随机旋转 | ±15° | 提升旋转鲁棒性 |
| 颜色抖动 | 亮度/对比度/饱和度 ±0.2 | 提升颜色鲁棒性 |

## 三、技术方案

### 3.1 整体技术路线

```text
数据加载 → 预处理与增强 → ResNet-18（ImageNet 预训练）
→ 替换分类头（102 类）→ 训练 → 评估与可视化
```

### 3.2 模型配置

| 配置项 | 值 | 说明 |
| :--- | :--- | :--- |
| **模型名称** | resnet18 | torchvision 内置 |
| **预训练权重** | ImageNet | 加载官方预训练参数 |
| **分类头** | 替换 fc 层 | 输出维度从 1000 改为 102 |
| **参数量** | ~11M | 轻量级，适合单卡训练 |

### 3.3 迁移学习策略（分阶段微调）

| 阶段 | 训练内容 | 学习率 | 训练轮数 | 目的 |
| :--- | :--- | :--- | :--- | :--- |
| **阶段一：特征提取** | 冻结主干，仅训练分类头 | 1e-3 | 10-15 | 快速适配花卉类别 |
| **阶段二：部分微调** | 解冻最后 3 个卷积组，同时训练分类头 | 1e-4 | 20-30 | 让高层特征适配花卉 |

### 3.4 训练配置

| 配置项 | 值 | 说明 |
| :--- | :--- | :--- |
| **损失函数** | CrossEntropyLoss | 多分类标准损失 |
| **优化器** | SGD | momentum=0.9 |
| **初始学习率** | 0.001 | 阶段一 |
| **学习率调度** | CosineAnnealing | 后期平滑衰减 |
| **批量大小** | 8 | 根据显存调整 |
| **最大训练轮数** | 50 | 配合早停 |
| **权重衰减** | 1e-4 | L2 正则化 |
| **早停策略** | patience=5 | 监控 test_loss |
| **随机种子** | 42 | 保证可复现 |
| **确定性模式** | 启用 | cudnn.deterministic=True |

### 3.5 工程化设计

| 设计 | 说明 |
| :--- | :--- |
| **配置驱动** | 用 config.yaml 管理所有超参数，代码与配置分离 |
| **实验管理** | 用 experiment_config.yaml 定义多组对比实验 |
| **目录规范** | 每组实验独立目录，自动保存配置、日志、模型、图表 |
| **可复现性** | 固定随机种子 + 确定性模式 + 配置快照 |
